# GXL Cam — камера для Pixel 9, которая снимает сразу в JPEG XL (.jxl)

Android-приложение на Camera2 + [libjxl](https://github.com/libjxl/libjxl) (эталонная
реализация JPEG XL). Снимки сохраняются в `Pictures/GXL Cam/*.jxl`.

## Два режима кодирования

| Режим | Что происходит | Когда выбирать |
|---|---|---|
| **Прямое кодирование** (по умолчанию) | Камера отдаёт несжатый кадр YUV_420_888 в полном разрешении (с шумоподавлением/резкостью в режиме HIGH_QUALITY), он сразу кодируется в JPEG XL. Промежуточного JPEG нет. | Лучшее качество на байт. Можно снимать **без потерь** (качество 100) и в **Display P3**. |
| **JPEG → JXL без потерь** | Камера делает обычный JPEG, libjxl пересжимает его *без единой потери* (~20 % меньше). Из `.jxl` можно восстановить исходный JPEG бит-в-бит. | Нужна полная совместимость: в любой момент можно вернуть оригинальный JPEG. |

Настройки (кнопка ⚙ или плашка сверху):

* **Качество** 50–100. В прямом режиме это качество JPEG XL: 90 ≈ distance 1.0
  («визуально без потерь»), 100 = математически без потерь (файлы большие).
  В режиме JPEG это качество исходного JPEG камеры.
* **Effort** 1–9 — сколько времени libjxl тратит на сжатие (7 — стандарт libjxl).
* **Display P3** — широкий цветовой охват (если камера его поддерживает; Android 14+).

Метаданные: в прямом режиме пишется собственный EXIF (дата/время с часовым поясом,
выдержка, ISO, диафрагма, фокусное, модель), ориентация хранится в самом кодстриме JXL.
В режиме JPEG сохраняются EXIF/XMP камеры.

## Возможности

* Предпросмотр 4:3 «что видишь, то и снимаешь», щипок/кнопки 0.5×–5× (на Pixel логическая
  камера сама переключает сверхширик/основной/теле), фокус и экспозиция по тапу.
* Съёмка кнопками громкости, звук затвора, фронтальная камера.
* Кодирование идёт в фоне — можно сразу снимать дальше (очередь до 3 кадров).
* Встроенный просмотрщик `.jxl` (Google Фото пока не показывает JPEG XL): зум, сведения
  о файле, «Поделиться», **«В JPEG»** — для файлов из режима JPEG восстанавливает
  оригинальный JPEG бит-в-бит, иначе перекодирует в JPEG q95. Просмотрщик также
  открывается для любых `image/jxl` из файлового менеджера.

## Установка

**Готовый APK.** Каждый push собирается в GitHub Actions (workflow *Build*):
откройте последний запуск → *Artifacts* → `gxl-cam-apk` → установите
`app-release.apk` (подписан debug-ключом, подходит для личной установки).

**Сборка самостоятельно.** Нужны Android Studio (или JDK 17 + Android SDK), NDK
28.2.13676358, CMake 3.31.6 и `git` в `PATH`:

```bash
./gradlew assembleRelease
adb install app/build/outputs/apk/release/app-release.apk
```

При первой сборке Gradle сам клонирует libjxl v0.12.0 (коммит закреплён и
проверяется) в `.deps/` — в репозитории исходников libjxl нет. Чтобы использовать
свою копию: `./gradlew assembleRelease -Pgxl.libjxl.dir=/путь/к/libjxl`.
Нативная часть всегда собирается с оптимизацией, даже в debug — иначе libjxl
кодирует в десятки раз медленнее.

## Устройство проекта

```
app/src/main/cpp/
  jxl_codec.{h,cc}   обёртка над libjxl без JNI: кодирование RGB, JPEG→JXL, декодирование, восстановление JPEG
  yuv.{h,cc}         YUV_420_888 → RGB (BT.601 full range, «fancy upsampling» хромы как в libjpeg)
  jni_bridge.cc      JNI для io.github.grailnight.gxlcam.codec.JxlNative
app/src/main/java/io/github/grailnight/gxlcam/
  camera/CameraController.kt   Camera2: превью, полный кадр JPEG/YUV, зум, фокус, Display P3
  PhotoPipeline.kt             фоновая очередь кодирования и сохранения
  storage/ExifWriter.kt        минимальный писатель EXIF/TIFF
  storage/PhotoStore.kt        сохранение через MediaStore
  viewer/ViewerActivity.kt     просмотрщик JXL
native-tests/                  тесты кодека на десктопе (запускаются в CI)
```

## Ограничения и что можно добавить

* Это не Google Камера: обработка HDR+/Night Sight доступна только ей. Приложение
  получает то, что отдаёт HAL камеры Pixel через Camera2 (с HIGH_QUALITY-шумодавом).
  Возможное развитие — режим Camera2 Extensions (Night), он тоже умеет отдавать YUV.
* Нет вспышки, видео, геометок и RAW. Хорошие кандидаты на будущее: RAW (DNG) → 16-бит
  JXL и 10-бит HDR (P010 → JXL с HLG/PQ).
* Размер кадра — максимальный для обычных потоков (на Pixel 9 это 12.5 Мп у основной
  камеры); режим 50 Мп (`SENSOR_PIXEL_MODE_MAXIMUM_RESOLUTION`) не используется.
* Только `arm64-v8a`. Для эмулятора x86_64 добавьте ABI в `abiFilters`.
